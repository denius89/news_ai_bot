# PulseAI — неактуальный проект / Discontinued

**Статус: разработка прекращена 6 октября 2026 года.**

PulseAI был экспериментальной платформой для сбора новостей, персональных ИИ-дайджестов и календаря событий с доставкой через Telegram.

Проект больше не развивается и не поддерживается. Репозиторий сохранён для исторической справки и изучения кода. Старые инструкции запуска, заявления о готовности к production, коммерческие предложения и прогнозы неактуальны.

Не подключайте к этому коду рабочие аккаунты, действующие ключи или персональные данные.

## Состав исторического проекта

- Python: сбор и обработка новостей, генерация дайджестов, Telegram-бот.
- React / TypeScript: веб-интерфейс.
- PostgreSQL / Supabase: слой хранения.
- Документация прежней реализации находится в `docs/`.

## Очистка опубликованных файлов

Из текущих файлов веток удалены резервные файлы окружения с ключами, персональные контакты, локальные пути владельца и конкретные идентификаторы администратора. Автоматическая ежедневная рассылка отключена.

Эта очистка не удаляет старые коммиты, сведения об авторах Git, старые pull requests, кэши GitHub или чужие копии. Ранее опубликованные ключи необходимо отозвать у соответствующих провайдеров. Текущую версию нельзя считать доказательством полного удаления данных из истории.
